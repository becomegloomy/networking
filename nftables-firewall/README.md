# Настройка firewall (nftables)

Настройка firewall в среде Linux (Ubuntu Server) с использованием `nftables`. Разрешение только необходимых протоколов и запрет ICMP/SSH с внешнего интерфейса.

## Что внутри

Настройка серверной и клиентской виртуальных машин, настройка DHCP-сервера и firewall (`nftables`).

- **Серверная ВМ:** Адаптер 1 - «Сетевой мост» (WAN, `enp0s3`), Адаптер 2 - «Внутренняя сеть» (LAN, `enp0s8`);
- **Клиентская ВМ:** Адаптер 1 - «Внутренняя сеть».

## Шаги выполнения

1. Настройка сетевых адаптеров в VirtualBox.
2. Установка DHCP-сервера: `sudo apt install isc-dhcp-server -y`.
3. Настройка `/etc/default/isc-dhcp-server` (интерфейс `enp0s8`).
4. Настройка `/etc/dhcp/dhcpd.conf` (подсеть `192.168.8.0/24`, диапазон `192.168.8.100-150`).
5. Включение маршрутизации: `sysctl -w net.ipv4.ip_forward="1"`.
6. Настройка NAT через `iptables` (MASQUERADE).
7. Установка и настройка `nftables` (создание таблиц, цепочек и правил фильтрации).
8. Написание скрипта `firewall.sh` для автоматизации.

## Проверка

1. Клиентская ВМ получает IP из диапазона DHCP (`ip a`).
2. С клиентской ВМ доступны внешние интерфейсы сервера (`ping 192.168.8.1`).
3. С клиентской ВМ доступен интернет (`ping 8.8.8.8`).
4. С внешнего интерфейса (Windows) **не** проходит `ping` до сервера (ICMP заблокирован).
5. С внешнего интерфейса **не** проходит подключение по SSH (порт 22 заблокирован).

## Конфигурации

- [firewall.sh](configs/firewall.sh) — скрипт настройки firewall (`nftables`), включающий правила фильтрации и NAT.

## Стек

- **Ubuntu Server 25.04** (VirtualBox);
- **Сеть:** `isc-dhcp-server`, `iptables`, `nftables`, `sysctl`;
- **Управление:** `Putty` (SSH).
