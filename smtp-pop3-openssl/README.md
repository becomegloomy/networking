# Обмен почтовыми сообщениями (SMTP, POP3)

Протоколы электронной почты SMTP и POP3, подключение к почтовым серверам и управление сообщениями через утилиту OpenSSL.

## Что внутри

Работа с почтовыми серверами Google (Gmail) с использованием командной строки и утилиты `openssl s_client`:

- установка защищенного соединения с SMTP-сервером (порт 465);
- отправка почтового сообщения с использованием протокола SMTP;
- установка защищенного соединения с POP3-сервером (порт 995);
- получение списка писем и чтение конкретного сообщения через POP3.

## Шаги выполнения

1. Открытие командной строки и переход в директорию с OpenSSL (`cd "C:\Program Files\OpenSSL-Win64\bin"`).
2. Подключение к SMTP-серверу: `openssl s_client -connect smtp.gmail.com:465 -quiet`.
3. Авторизация через SMTP: команды `helo domain.local`, `auth login` и ввод логина/пароля в Base64.
4. Отправка письма: команды `MAIL FROM`, `RCPT TO`, `DATA`, ввод текста и точки `.`.
5. Подключение к POP3-серверу: `openssl s_client -connect pop.gmail.com:995 -quiet`.
6. Авторизация через POP3: команды `USER` и `PASS`.
7. Просмотр ящика (`LIST`) и получение письма (`RETR 6`).

## Проверка

1. Успешная авторизация на SMTP (код `235 2.7.0 Accepted`).
2. Успешная отправка письма (код `250 2.0.0 OK`).
3. Письмо появилось во входящих у получателя (проверено через веб-интерфейс).
4. Успешная авторизация на POP3 (код `+OK Welcome`).
5. Получение списка писем (команда `LIST`) и чтение 6-го письма (команда `RETR 6`).
