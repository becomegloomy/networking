# networking

Работы по сетям ЭВМ и телекоммуникациям: сканирование сети, анализ трафика, работа с почтовыми протоколами через OpenSSL и настройка firewall (nftables).

## Что внутри

- **`nmap-scanning/`** - сканирование локальной сети утилитой NMAP: поиск активных хостов, открытых портов и определение ОС;
- **`tcpdump/`** - анализ сетевого трафика утилитой TCPDUMP: перехват ARP, ICMP и TCP-пакетов;
- **`smtp-pop3-openssl/`** - работа с почтовыми протоколами SMTP и POP3 через OpenSSL: отправка и получение писем вручную;
- **`nftables-firewall/`** - настройка firewall на базе `nftables` для фильтрации трафика и запрета ICMP/SSH с внешнего интерфейса.

## Стек

- **NMAP 7.98** (сканирование сети);
- **TCPDUMP** (анализ трафика);
- **OpenSSL** (работа с SSL/TLS и почтовыми протоколами);
- **nftables / iptables** (firewall);
- **Среда:** Windows, WSL2 (Ubuntu), VirtualBox;
- **Протоколы:** TCP/IP, ARP, ICMP, SMTP, POP3, DHCP, NAT.
