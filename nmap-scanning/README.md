# Утилита NMAP

Использоватние утилиты NMAP для сканирования сети, определения активных хостов, открытых портов и типов операционных систем.

## Что внутри

Сканирование домашней локальной сети с помощью утилиты NMAP на компьютере под управлением Windows:

- определение адреса сети и IP-адреса компьютера;
- сканирование сети для поиска активных хостов;
- сканирование каждого активного хоста на наличие открытых портов;
- попытка определения типа операционной системы.

## Шаги выполнения

1. Установка NMAP: `choco install nmap` (через Chocolatey).
2. Определение адреса сети: `ipconfig` (сеть `192.168.0.0/24`, IP `192.168.0.7`).
3. Сканирование сети списком: `nmap -sL 192.168.0.0/24`.
4. Поиск активных хостов: `nmap -sn 192.168.0.0/24` (найдено 5 хостов).
5. Сканирование портов: `nmap -r 192.168.0.7` (найдены порты 135, 139, 445, 3306).
6. Определение ОС: `nmap -O 192.168.0.7`.

## Проверка

1. NMAP успешно установлен и выводит версию.
2. Определён адрес сети (`192.168.0.0/24`).
3. Найдено 5 активных хостов.
4. Найдены открытые TCP-порты (msrpc, netbios-ssn, microsoft-ds, mysql).
5. Попытка определить ОС (утилита не смогла точно определить версию).
