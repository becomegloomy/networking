# Утилита TCPDUMP

Работа с консольным приложением TCPDUMP для анализа и перехвата сетевого трафика.

## Что внутри

Перехват и анализ сетевых пакетов с помощью утилиты `tcpdump` в среде Linux:

- определение перечня сетевых интерфейсов;
- перехват ARP-пакетов;
- перехват ICMP-пакетов;
- фильтрация и анализ TCP-трафика;
- определение адресов хостов назначения.

## Шаги выполнения

1. Установка WSL и Ubuntu на Windows: `wsl --install`, затем `wsl --install -d Ubuntu`.
2. Установка утилиты TCPDUMP: `sudo apt install tcpdump`.
3. Просмотр списка интерфейсов: `tcpdump -D`.
4. Генерация и перехват ARP-трафика: `sudo tcpdump -i eth0 arp`.
5. Генерация (ping) и перехват ICMP-трафика: `sudo tcpdump -i eth0 icmp`.
6. Генерация (curl) и перехват TCP-трафика: `sudo tcpdump -i eth0 tcp`.

## Проверка

1. Утилита TCPDUMP успешно запускается с правами суперпользователя.
2. В выводе `tcpdump -D` отображаются интерфейсы (`eth0`, `lo`, `any` и др.).
3. В перехвате ARP видны запросы (`Request who-has`) и ответы (`Reply ... is-at`).
4. В перехвате ICMP видны пары `Echo Request` и `Echo Reply` с указанием `id` и `seq`.
5. В перехвате TCP видны этапы установки соединения (флаги `S`, `P`, `F`, `.`) и IP-адреса назначения.
